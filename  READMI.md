# Rock Paper Scissors

A simple Rock Paper Scissors game built with JavaScript as part of [The Odin Project](https://www.theodinproject.com/).

## About

This project is a console-based game where a player plays against the computer. The game consists of five rounds, and the final scores determine the winner.

## Features

- Random computer choice: rock, paper, or scissors
- Player input using a prompt
- Score tracking for both players
- Round results displayed in the console
- Final score and winner announcement after five rounds

## Technologies Used

- HTML
- JavaScript
- Git and GitHub

## How to Play

1. Open the `index.html` file in your browser.
2. Open the browser Developer Tools and go to the Console.
3. Enter `rock`, `paper`, or `scissors` when prompted.
4. Play five rounds against the computer.
5. Check the final scores and winner in the console.
